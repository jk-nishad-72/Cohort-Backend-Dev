
# 🚀 Model Context Protocol (MCP) – Overview & Example Server

## 📌 What is MCP?
**MCP (Model Context Protocol)** is an **open protocol** for connecting large language models (LLMs) or AI applications to external systems such as tools, APIs, databases, or resources.  

Instead of custom integrations for every system, MCP provides a **standard way** for:
- Exposing **Tools** (functions the model can call)
- Sharing **Resources** (read-only data, e.g. files, APIs)
- Providing **Prompts** (predefined templates/workflows)

👉 Official site: [modelcontextprotocol.io](https://modelcontextprotocol.io)

## 🔄 Transport
MCP supports multiple **transports** (ways of communication between client & server):

- **STDIO** → Local, lightweight, communicates via stdin/stdout.  
- **HTTP(S)** → For remote/online MCP servers.  
- **Server-Sent Events (SSE)** → Streaming updates.  
- **WebSockets** → Real-time communication (future use).
